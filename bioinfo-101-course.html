生物信息学导论：从中心法则到数据库

什么是生物信息学

生物信息学 = 生物学 + 信息科学：用计算机处理海量的生命数据，回答"这段序列是什么、有什么功能"。

21 世纪初，人类基因组计划完成后，生命科学的数据量爆炸式增长：一次实验就能测出几十亿个 DNA 字母。这些字母里藏着疾病的原因、药物的靶点、进化的秘密——但人眼根本读不过来，必须借助计算机。

图书馆有上亿本书，但没人读过。生物信息学就是那个"编目员 + 检索系统 + 阅读理解机器人"：先把书按字母分类入库（数据库），再让你输入几个词就能找到相关章节（检索比对），最后帮你总结这本书讲了什么（功能注释）。

它研究的对象可以归为三大类：

  • 序列（Sequence）：DNA/RNA/蛋白质的线性字母串，比如 ATCGATCG...
  • 结构（Structure）：蛋白质折叠后的三维形状，决定它能"抓住"谁
  • 功能（Function）：这个基因/蛋白质在细胞里干什么，和哪些疾病相关
点击卡片翻面，认识三个核心对象
序列
由 A/T/C/G（DNA）或 A/U/C/G（RNA）或 20 种氨基酸（蛋白质）组成的线性字符串，是一切分析的起点。
结构
蛋白质的三维折叠形态，由氨基酸序列决定（类似一根绳子自己缠成的结），决定它的功能。
功能
基因在细胞中的角色：催化反应？运输物质？调控其他基因？通常通过实验或计算预测得出。

中心法则：生命的信息流

DNA 像图纸存档（转录）成 RNA 模板，RNA 再被翻译（Translation）成蛋白质机器——信息只朝一个方向流动。

1958 年克里克提出中心法则（Central Dogma）：遗传信息从 DNA → RNA → 蛋白质单向传递。这三步都有专门的名字：

一步步拆解中心法则
① 复制（Replication）：细胞分裂时，DNA 双链解开，各自作为模板合成新链。一个变两个，信息完整拷贝。
② 转录（Transcription）：以 DNA 一条链为模板，合成信使 RNA（mRNA）。相当于把档案室里的一张图纸复印一份拿到车间。
③ 翻译（Translation）：核糖体读取 mRNA，每三个碱基（一个密码子）对应一种氨基酸，串成蛋白质。
④ 逆转录（Reverse Transcription）：某些病毒（如 HIV）能把 RNA 反转录回 DNA——这是对原始法则的重要补充。
把细胞想成一家餐厅：DNA 是总部保存的配方总册（从不外借）；转录是抄写下一张"今日特餐单"（mRNA）；翻译是厨师照单子做菜（蛋白质）。逆转录病毒就像间谍，能把菜反推出配方再偷偷送回总部。
生物信息学分析大多围绕"法则的哪一环出了问题"：基因突变（复制出错）、表达量变化（转录多少）、蛋白质结构异常（翻译产物）……

中心法则是生信的"语法规则"：一切数据分析都在解读这条信息链的某个环节。

核心数据库：生信的图书馆

全世界的序列、结构、基因组注释都存在公开数据库里；学会查库，等于拿到了生信的通行证。

没有人重新测序——绝大多数分析都是从"去数据库查"开始的。四大必知数据库：

数据库维护方存什么什么时候用
GenBank / NCBI美国 NIH所有公开的 DNA/RNA 序列查一个基因长什么样、比对未知序列
UniProt国际联盟蛋白质序列与功能注释查某蛋白的功能、结构域、疾病关联
PDBwwPDB 联盟实验测定的 3D 结构看蛋白质长什么样、找药物结合口袋
EnsemblEBI / WTSI参考基因组与注释查基因在染色体上的位置、转录本
四个库像四种工具书：GenBank 是"词典"（所有词），UniProt 是"百科"（词条详解），PDB 是"图鉴"（照片），Ensembl 是"地图册"（基因坐落哪条街）。

你想知道某个蛋白质的三维结构（X 射线晶体数据），应该去哪个数据库？

查库能力 = 生信童子功。遇到任何基因/蛋白，先去 NCBI Gene 和 UniProt 搜一圈，80% 的问题已经有答案。

测序技术：从读一句到读全书

一代测序读得准但慢，二代测序（NGS）便宜快但片段短，三代测序读得长但错误率高——各有适用场景。

三代测序对比

代际代表技术读长特点
一代Sanger 双脱氧法~1000 bp准确（>99.9%），慢且贵，适合验证
二代Illumina 边合成边测序100–300 bp便宜、通量巨大，需拼接，主流技术
三代PacBio / Oxford Nanopore10kb–1Mb超长读长，错误率偏高，适合组装
读长像读文章：一代是逐字精读校对，二代是把书撕成几百字的碎片再拼回去（碎片太多容易拼错），三代是每次抓一大页——可能看错几个字，但章节顺序一目了然。
读长模拟：拖动滑块切换测序平台，看一条基因被"读"成什么样

测序数据的一切下游分析（比对、组装、变异检测）都由"读长 + 错误率"这两个参数决定。先想清楚数据怎么来的，再选分析工具。

你想组装一个全新的细菌基因组（没有参考序列），读长越长越好，你会优先选？

没有最好的测序仪，只有最合适的测序策略。问题决定技术，而不是反过来。

生信分析的基本流程

99% 的生信项目都遵循同一骨架：拿到原始数据 → 质控 → 比对/组装 → 定量/检测 → 注释 → 可视化。

不管是 RNA-seq、全基因组测序还是宏基因组，流程几乎一样：

动手排一排：NGS 数据分析的标准流程顺序
比对到参考基因组（Alignment）
原始数据质量控制（QC）
结果注释与可视化
定量或变异检测（Calling）
去除接头与低质量 reads（Trimming）
记住这个六步骨架：QC → Trim → Align → Call → Annotate → Visualize。后面每门进阶课都是在其中某一步上深挖。

为什么 QC 永远排第一？

"垃圾进，垃圾出"（Garbage in, garbage out）。原始 FASTQ 文件里可能混着测序接头、低质量碱基、rRNA 污染——不清理就分析，后面全是假阳性。常用工具：FastQC 看质量分布，Fastp / Trimmomatic 执行清理。

新手最常见错误：拿到数据直接跑比对，跳过质控。结果差异表达基因列表里全是技术噪音。
质量阈值演示：拖动 Q 值下限，看多少碱基会被保留

质量值 $Q = -10\log_{10} P(\text{错误})$：Q20 表示 1% 错误率，Q30 表示 0.1%。常用过滤线是 Q30。

常见误区与进阶地图

生信不是跑软件，是"用统计思维回答生物问题"；工具会过时，统计和生物学直觉不会。

四大常见误区

误区一：黑箱依赖。把参数默认值当真理。每个工具的参数都对应一个统计假设，默认值是为"典型数据"设计的，不一定适合你的。
误区二：P 值崇拜。测了 2 万个基因，光凭 P<0.05 会筛出约 1000 个假阳性。必须做多重检验校正（FDR / Benjamini-Hochberg）。
误区三：相关当因果。基因 A 和疾病相关，不代表 A 导致疾病——可能是反向因果，也可能有共同原因。
误区四：只看 p 不看效应量。差异表达倍数 0.0001 也可能显著，但生物学上毫无意义。
