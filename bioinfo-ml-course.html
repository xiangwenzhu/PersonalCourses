机器学习 × 生物信息学：从特征到预测

ML 在生信中的应用全景

机器学习正在重塑生物信息学：从序列分类、结构预测，到药物筛选和疾病诊断，凡是"从数据找规律"的任务，都有 ML 的身影。

生物数据爆炸式增长：一次测序能产生数亿条序列、数万个基因的表达值。人脑无法从这些高维数据里直接看出规律，而机器学习恰好擅长这件事——从大量样本中学习"特征 → 结论"的映射。

传统生信分析像"查字典"（按固定规则比对、注释）；机器学习像"总结经验"（看过一万个例子后，判断新来的这个属于哪类）。规则写不全的问题，经验可以补上。

ML 在生信中的共同范式：把生物对象（序列、结构、表达谱）表示成数值特征向量 $\mathbf{x}$，让模型学习 $f(\mathbf{x}) \to y$ 的映射，其中 $y$ 是我们关心的标签（类别、亲和力、风险评分）。

记住这个总框架：生物对象 → 特征 → 模型 → 预测。这门课的后面五章，就是把这条链路拆开，一环一环讲清楚。

监督 vs 无监督：两种学习范式

有标签用监督学习（分类/回归），没标签用无监督学习（聚类/降维）。生信里两类任务各占半壁江山，选错范式是新手最常见的错误。

监督学习：有标准答案的练习册

训练数据带标签 $y$，模型学习从特征到标签的映射：

  • 分类：$y$ 是离散类别。例：判断一段 DNA 是否为增强子（是/否）；预测 SNP 是否为致病突变。
  • 回归：$y$ 是连续数值。例：预测药物与靶点的结合亲和力（Kd）；预测基因表达量。

无监督学习：自己找结构的拼图

没有标签，模型自行发现数据中的结构：

  • 聚类：把相似样本分组。例：对肿瘤样本的基因表达谱聚类，发现新的分子亚型（如乳腺癌的 Luminal A/B、HER2+、Basal）。
  • 降维：把高维数据压到 2-3 维便于观察。例：t-SNE/UMAP 可视化单细胞 RNA-seq 数据，识别细胞类型。
监督学习像"带着答案刷题"——每道题（样本）都有标准答案（标签），刷多了就会做新题。无监督学习像"把一堆袜子按相似度配对"——没人告诉你哪双该配，你得自己发现"颜色、花纹接近"。

你有一组肿瘤病人的基因表达数据，没有任何亚型标签，想自动发现病人分成几类，应该用什么方法？

判断范式的口诀：先问"我有标签吗？"有 → 监督（预测类问题）；没有 → 无监督（探索结构）。生信中大量有意思的问题是"半监督"：少量有标签 + 大量无标签，这个进阶话题 L4 会提到。

特征工程：把序列变成数字

模型不能直接读 DNA 序列，必须先编码成数值向量。k-mer 频率是最经典的序列特征；此外还有物化性质、进化保守性、结构特征。

为什么特征工程是"最后一公里"

同样的分类任务，用朴素特征 + 简单模型，可能不如用好特征 + 简单模型。特征决定了模型的上限——经典机器学习（随机森林、SVM）的性能高度依赖人工设计的特征。

四类常用特征

特征类型内容生信应用
k-mer 频率长度为 k 的子串在序列中出现的频率物种分类、启动子预测、RNA 结合位点
物化性质GC 含量、分子量、疏水性、电荷分布蛋白质功能分类、抗菌肽预测
进化保守性PhastCons/GERP 保守性得分致病突变识别、功能元件定位
结构特征二级结构、溶剂可及性、无序区翻译后修饰位点预测、结合位点识别

k-mer 特征的大小：$4^k$（DNA，4 种碱基）。$k=2$ 时 16 维，$k=3$ 时 64 维，$k=4$ 时 256 维——维度随 k 指数增长，这也是高维小样本问题的来源之一。

k-mer 特征提取器：输入 DNA 序列，实时计算 k-mer 频率条形图

k-mer 能捕获"序列上下文"信息：比如启动子区富含 "TA" 和 "TATA" 类 motif，k-mer 频率向量中这些分量会偏高，模型据此学习区分。

DNA 序列用 k=3 做 k-mer 特征，特征向量是多少维？

特征工程是经典 ML 的核心竞争力。好消息是：深度学习（L3）能自动学特征，把这一步交给模型——但它不是免费的午餐，需要更多数据和算力。

模型评估：你的模型真的准吗

训练集上的高分可能是假象。交叉验证、ROC/AUC 是生信 ML 的标配评估工具；过拟合是头号敌人，正则化是对策。

为什么不能只看训练集准确率

模型在训练数据上表现好，可能只是"背答案"。真正的考验是在没见过的数据（测试集）上的表现。评估分类器最常用的工具是 ROC 曲线。

ROC 与 AUC：分类器的体检报告

分类器输出的是一个分数，我们需要一个阈值把它切成"正类/负类"。阈值移动时：

  • 真阳性率（敏感度）：$TPR = \dfrac{TP}{TP + FN}$
  • 假阳性率：$FPR = \dfrac{FP}{FP + TN}$

以 FPR 为横轴、TPR 为纵轴画出的曲线就是 ROC 曲线，曲线下面积 AUC 越大越好（1.0 = 完美，0.5 = 瞎猜）。

ROC 曲线生成器：拖动分类阈值，看 TPR/FPR 与 AUC 如何变化

交叉验证：把数据用充分

数据宝贵，不能浪费。K 折交叉验证把数据分 K 份，轮流拿 K-1 份训练、1 份验证，取平均性能——生信中常用 5 折或 10 折。

过拟合演示：拖动滑块增加模型复杂度（多项式阶数），看训练误差和测试误差何时"分叉"

生信数据"小样本 + 高维度"的特点让过拟合极其常见：100 个样本、10000 个特征，随便一个模型都能"背下"训练集。必须交叉验证 + 独立测试集双保险。

你的模型在训练集 AUC = 0.98，但在独立测试集上 AUC = 0.62，最可能的解释是？

评估是 ML 的"质检环节"：交叉验证选模型、ROC/AUC 报性能、警惕过拟合。这三个工具会贯穿你之后所有的生信 ML 项目。

深度学习：让模型自己学特征

CNN 从序列中自动提取 motif 特征（DeepBind），RNN/LSTM 建模长程依赖，Transformer 架构（ESM）把蛋白质当作"语言"来学习。

为什么深度学习适合序列数据

回想 L2：k-mer 需要人工选 k 值、手工统计频率。深度学习把这一步也纳入学习：卷积核就是可学习的 motif 探测器。模型自己学"什么模式的序列重要"，不用人告诉它。

三条技术路线

深度学习在生信中的演进
① CNN 处理序列（DeepBind, 2015）：把 DNA/RNA 序列 one-hot 编码后过卷积层，自动学习转录因子结合的序列模式（motif），性能超越人工特征 + SVM。
② RNN/LSTM 建模长程依赖：序列信息可以从远处传递（如一个基因的增强子可能在几万个碱基之外），LSTM 的门控机制能记住长距离上下文。例：DeepCRISPR 预测 gRNA 效率。
③ Transformer 与蛋白质语言模型（ESM, 2021+）：把氨基酸当"单词"、蛋白质当"句子"，用自注意力机制建模全局依赖。ESM-2、AlphaFold2 的 Evoformer 都属于这一路线，能从未标注的海量蛋白序列中学到进化约束信息。
传统 ML：你给厨师一本菜谱（人工特征），他照着做菜。深度学习：你只做一件事——把食材（原始序列）给它，告诉它"好吃"的标准（损失函数），它自己摸索怎么做。

one-hot 编码：序列怎么进神经网络

序列 A T G C → one-hot 矩阵（4 列 × 序列长度）：

A → [1, 0, 0, 0]
T → [0, 1, 0, 0]
G → [0, 0, 1, 0]
C → [0, 0, 0, 1]
深度学习的隐含假设：数据够多。ESM 用了 2.5 亿条蛋白质序列预训练——这种"大数据红利"在多数湿实验场景难以复制，这也是 L4 要讨论的挑战。

DeepBind 用 CNN 处理 DNA 序列，卷积层学到的主要是什么？

深度学习把"特征工程"也变成了学习的一部分：CNN 学局部 motif，RNN 学长程依赖，Transformer 学全局注意力。这条路线从 2015 年 DeepBind 开始，到今天 ESM 和 AlphaFold2，已经成为生信 ML 的主流。

可解释性与现实挑战

模型准还不够——生物学家要问"为什么"。SHAP 值拆解特征贡献；同时要正视数据偏差、小样本和跨域失效这三大现实挑战。

可解释性：让模型开口说话

在生信中，"黑盒模型给出一个预测"往往不够。如果你预测某突变致病，审稿人和临床医生会追问：依据是什么？

  • SHAP 值：把每个特征对单次预测的贡献量化分解。正 SHAP = 推高预测值，负 SHAP = 压低预测值。例：某突变预测为致病，SHAP 显示"该位点保守性得分"贡献了 +0.35，是主要依据。
  • 梯度归因（ saliency / Integrated Gradients）：在序列模型上，看"哪些碱基对预测最重要"，可视化出来往往就是已知的 motif。

SHAP 的核心思想基于博弈论的 Shapley 值：对每个特征 $i$，计算它在所有可能的特征组合中的边际贡献的加权平均：

$$\phi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!(n-|S|-1)!}{n!}\left[f(S \cup \{i\}) - f(S)\right]$$

SHAP 像"分账"：一次预测的分数是团队合作的成果，SHAP 给每个特征（队员）分配合适的贡献份额——谁干得多、谁干得少，一目了然。
