机器鸭感知与VLA

系列目录

从会走到会看

前九课让鸭子有了「小脑」——会走、会摔、会爬起；这一课给它装「大脑」：用视觉理解世界、听懂自然语言指令，完成从「运动机器」到「智能体」的惊险一跃。

能走，只是入场券。Microduck 的爆火不只因为可爱，更因为它能「听懂人话」：你说「去厨房帮我拿杯水」，它真的摇摇摆摆走过去、认得杯子、弯腰、抓取——这背后是视觉与语言两大能力的合流。这一课的主角是近年机器人圈最热的技术范式：VLA（Vision-Language-Action，视觉-语言-动作模型）。

先建立整体地图：感知系统把「摄像头画面 + 语言指令」翻译成内部表示，再由 VLA 模型把内部表示直接翻译成底层控制信号（关节位置/力矩）。它和第 09 课的 RL 不是替代关系：VLA 管「理解要做什么」，RL 管「把它做出来」——前者是任务的翻译官，后者是动作的执行官。

把鸭子想成一位刚入职的「机器实习生」：RL 训练是它上的「体校」——教会它怎么控制肌肉；VLA 是它的「大学教育」——教会它看图纸（视觉）、听懂需求（语言）、把需求拆成动作计划（决策）。两个都毕业，才算「可用之才」。
核心定义：VLA（Vision-Language-Action）模型把「看见的画面 + 听懂的指令」作为输入，直接输出机器人的动作指令。它是多模态大模型（VLM）在机器人领域的延伸——把「文字接龙」的能力，迁移到「动作接龙」。
点击卡片翻面：这一课的三个关键词
视觉感知
用摄像头 + 神经网络，从二维画面里提取三维世界的信息：哪是地面、哪是障碍、杯子在哪、离我多远。是「看懂」。
语言理解
把「去厨房拿杯水」解析成「目标位置 + 目标物体 + 期望动作」的结构化任务，是「听懂」。
VLA 模型
视觉-语言-动作大模型：把「看懂 + 听懂」的联合表示，直接解码成关节控制信号，是「做到」的桥梁。

填空：VLA 三个字母分别代表 、 与 。

一句话记住：RL 让鸭子「会动」，VLA 让它「懂行」。这一课沿着「会看 → 听懂 → 做到」的链条，逐一拆开。

让鸭子看见世界

一台微型相机的成本不到几美元，却能让鸭子从「闭着眼走」变成「看着走」：检测地面与障碍、定位目标物体、估计自身位置——视觉是性价比最高的「感官升级」。

Microduck 的头部装有一颗微型相机（具体型号官方未完全公开，教学估算为低成本 RGB 相机模组，以厂商规格书为准）。不要小看这颗「眼睛」：对双足机器人而言，视觉不是锦上添花，而是稳定性的第二支柱——第 05 课的 IMU 告诉你「我在倒」，视觉告诉你「前面有台阶、左边是墙」，两者互补才能又稳又聪明。

视觉为鸭子做三件事：

  • 语义分割：把画面逐像素分类（地面、地毯边、电线、障碍）——是落脚规划（第 07 课）的眼睛版。
  • 目标检测：找到「杯子」「拖鞋」「你伸过来的手」在哪——是抓取与交互的前提。
  • 视觉里程计：对比连续帧，估计「我走了多远、往哪偏」——与 IMU 融合，得到比单独任一种都准的位姿估计。
夜航的飞机：仪表（IMU）告诉它姿态，但「前方有山」只能靠雷达（视觉）。单看仪表能飞平，不知道往哪飞；单看雷达知道往哪飞，但一个气流颠簸就慌了。双足鸭子同理——IMU 管「别倒」，视觉管「别撞、别踩空、找得到东西」。

为什么双足机器人通常要「IMU + 视觉」双路感知，而不是只靠其一？

填空：从画面逐像素判断「这是地面还是障碍」的任务叫 ；通过对比连续帧估计自身运动叫 。

视觉三件套：分割认路、检测找物、里程计定位。它和 IMU 是互补搭档，不是替代品。下一章看这些画面如何变成网络能懂的「表示」。

视觉编码器与 token

神经网络看不懂像素，只认「token」——视觉编码器把画面切成一块块小补丁，各自压成一个向量，再配上位置信息：一张图就变成了一串可以像文字一样被处理的「视觉单词」。

多模态大模型的第一步，是把图像翻译成它能处理的序列。做法叫视觉编码器（如 ViT、CLIP 或 SigLIP）：把图片切成固定大小的「补丁」（patch，例如 14×14 像素），每个补丁经一层神经网络压成一个高维向量——这个向量就是视觉 token。一张 224×224 的图会变成 $(224/14)^2 = 256$ 个视觉 token，如同 256 个「视觉单词」。

为什么切成块而不是整图压一个向量？因为位置信息太重要了：「杯子在画面左边」和「杯子在右边」对应完全不同的动作。切块后，每个 token 天然携带「我是第几块」的空间坐标；更重要的是，自注意力机制让任意两个 token 都能「对话」——地面的 token 可以和杯子的 token 直接交换信息，模型因此能推理「杯子在地毯上，而地毯有点滑」这种跨物体的关系。

把一幅画拆成 256 块拼图，每块写一个便签（这块是什么、在原图哪一行哪一列），再把所有便签钉在公告板上。语言模型读这些便签，就像读一行行文字——它不用「看」画，读便签就能推理出「猫在沙发上」。视觉编码器，就是负责写便签的那位。
视觉编码器 = 把图像切成补丁 → 每块压成一个向量（视觉 token）→ 拼成序列。它让「图像」和「文字」在神经网络里变成了同一种数据结构——这是所有多模态大模型能成立的地基。
延伸：CLIP / SigLIP 这类编码器为何常被选作视觉前端？

因为它们在「图文配对」的海量数据上预训练过，天然知道「这张图和哪段文字最配」——这个语义空间对机器人极有用：把「杯子」这个词和画面里杯子的视觉 token 关联起来，几乎不需要额外训练。代价是它们的分辨率通常不高（224 或 384），看远处小目标吃力——复刻时可选更高分辨率或加 ROI 放大。

把图像切成 14×14 像素的小块、每块压成一个向量，这些向量在模型里被称为什么？

填空：一张 224×224 的图按 14×14 分块、不重叠，共得到 个视觉 token。

视觉编码器把像素翻译成 token，让图像第一次能被「读」。有了视觉 token 和文字 token，下一步就是把它们接到一起，听指令干活——这就是 VLA。

模仿学习与 VLA

VLA 的诞生靠两步：先用海量图文数据学会「看懂 + 听懂」，再用真实遥操作数据做模仿学习，教会它「看懂听懂之后该动手」。数据质量，而不是模型大小，往往决定最终效果。

VLA 模型不是从零训练的，它的成长分两段。第一段是预训练：喂给它互联网规模的图文对（ captioned images ），让它学会视觉与语言的联合表示——「画面里有什么」「这个物体通常叫什么」。这段训练只让模型「会看会说」，还「不会动手」。

第二段是模仿学习（Imitation Learning）：让真人戴着遥操作设备「手把手」教它——你戴着机械臂控制器，把「看到杯子 → 走过去 → 弯腰 → 抓取」整段操作演示一遍，机器人记录当时的视觉、语言指令、以及你输出的每一个动作。训练时，模型学习在给定「视觉 + 指令」时，输出和真人一样的动作序列。这一步的关键是数据质量与多样性：演示者动作毛躁，它就学毛躁；演示只覆盖了平地，它上了地毯就懵。

带实习生：第一阶段让他读行业报告（预训练，建立通识）；第二阶段你坐他旁边，演示一遍「怎么给客户回邮件」——他模仿你的措辞、顺序、格式。教得好不好，不取决于他读书多少，而取决于你的演示够不够清晰、覆盖的场景够不够全。

VLA 的模仿学习阶段，对最终机器人表现影响最大的因素通常是？

填空：VLA 训练两阶段——先在图文对上 建立视觉-语言表示，再用遥操作数据做 学会「动手」。

VLA = 预训练（看懂听懂）+ 模仿学习（动手模仿）。数据是新的代码——演示的质量与多样性，比网络结构更决定最终表现。下一章亲手在实验台里对比「粗糙演示 vs 平滑演示」的差距。

模仿学习轨迹实验台

同一个「伸手抓物」任务，演示数据的质量直接决定学到的轨迹：平滑演示学出干净利落的动作，毛糙演示学出抖抖索索的轨迹——拖动「演示噪声」，亲眼见证垃圾进、垃圾出。

模仿学习有个朴素到残酷的定理：学到的行为分布，不会好于演示分布（garbage in, garbage out）。下面的实验台用预计算的方式复现这个因果：目标轨迹是一条从起点到杯子的理想曲线；「演示噪声」模拟真人遥操作时手抖、犹豫、路径迂回的程度；「平滑正则」模拟训练时对动作变化率的惩罚强度。

轨迹对比实验台：看演示噪声如何把「干净动作」污染成「抖动怪」

读图要点：

  • 蓝线（理想轨迹）：最短路径，速度曲线平滑——这是「完美老师」。
  • 橙点（实际学到的轨迹）：带噪声与迂回的演示 + 训练时的平滑正则，共同塑造的最终策略输出。
  • 红虚线（无正则）：把平滑正则关掉，学到的轨迹会「忠实」复现演示的毛糙——动作抖、能耗高、还更容易撞翻东西。
跟一位手抖的师傅学书法：他每个笔画都抖、还老爱绕弯。你若只会「照着写」（无正则），写出来必然同样抖；若你心里另有一把「写顺」的尺（平滑正则），就能滤掉一部分毛糙，但滤不掉系统性错误——师傅若总是把「永」字少写一捺，你再顺也补不回来。

演示数据里总包含「手抖」（高频小噪声），下列哪种做法最能防止策略学到这些抖动？

填空：模仿学习中「学到的行为分布不会好于演示分布」被概括为 ；抑制动作抖动的常用正则项惩罚 。

数据决定上限，正则逼近上限。实验台里把平滑正则拉到 0、演示噪声拉满，看「忠实复现毛糙」的灾难性效果——那是一行代码的差别。

语言指令与动作解码

「去厨房拿杯水」如何变成关节信号？VLA 的解码阶段把内部表示翻译成「动作 token」——每个动作 token 对应未来一小段的关节目标，再交给底层伺服执行；翻译的颗粒度，决定了鸭子是「聪明」还是「卡顿」。

VLA 的最后一步，是把 Transformer 内部那串「视觉+语言」的表示，解码成机器人能执行的信号。主流做法有两种，Microduck 类产品的具体实现官方未公开，教学层面对比其取舍：

  • 动作 token 化（如 RT-2、Octo 的路线）：把连续的动作空间离散成有限个「档位」（如关节角 −30°、−29°… 各是一个 token），模型像生成文字一样逐个生成动作 token。优点是直接复用语言模型的全套解码技术；缺点是离散化引入精度损失。
  • 连续解码（如扩散策略 Diffusion Policy）：直接输出连续动作向量（甚至一次输出未来一整段动作「块」），通过扩散模型逐步去噪生成。优点是精度高、动作平滑；缺点是与语言模型架构差异大，工程接入更复杂。

无论哪种，最终都要回到第 06、08 课的老朋友：底层伺服。VLA 输出的通常是「未来几百毫秒的关节目标轨迹」，以 30–50Hz 更新；底层 PID/RL 策略以 200–1000Hz 跟踪。两层之间的时间对齐和限幅（第 09 课部署三关）依然是硬约束。

最常见误区：以为 VLA 输出「电压」直接驱动电机。实际上 VLA 产出的是「高层意图」（关节目标轨迹），真正的电流环、力矩环仍在底层伺服。把两者混为一谈，要么控制频率跟不上（大模型推理慢），要么安全保护缺位（大模型幻觉输出危险动作）。分层，是让大模型安全上机器人的唯一解。
交响乐指挥和乐手：指挥（VLA）不自己拉小提琴，他给出「这段要柔、渐强」的意图，乐手（底层伺服）以毫秒级反应把每个音拉准。若指挥越俎代庖去抠每个手指动作，整场演出必然慢半拍；若乐手不听指挥，音乐就散了。分层协作，缺一不可。

为什么 VLA 模型通常不以 1000Hz 直接输出力矩控制电机？

填空：VLA 输出的是未来一段关节目标轨迹，属于 控制层；真正以高频跟踪它的是底层 层。

解码两条路线：动作 token 化（复用 LM 技术栈）与连续扩散（精度与平滑）。无论哪条，最终都回落到「高层出意图、底层管执行」的分层架构。下一章看 Microduck 式的 VLA 落地，工程上有哪些取舍。

Microduck 式 VLA 落地

把 VLA 塞进一只 25 厘米、售价几百美元的鸭子，是一场「算力、功耗、延迟」的三角平衡：模型要蒸馏到小得离谱，推理要压到实时，动作还要保留「可爱」——工程智慧藏在每一个妥协里。

实验室里 VLA 可以跑在 A100 上，Microduck 的「大脑」却只有一颗低功耗嵌入式芯片。落地要做一整套「减肥」：

  • 模型蒸馏：用大型 VLA 当「老师」，训练一个几兆参数的小模型当「学生」，把老师的「视觉→动作」映射逼近过来。蒸馏后精度略降，但换来在嵌入式芯片上实时运行。
  • 分辨率与帧率折中：相机喂给网络的图像从 224 降到 160 甚至 128，帧率从 30 降到 10–15——省算力，但远处小物体更难看清。补救：只对「用户指名的目标区域」做 ROI 放大。
  • 云边协同（可选）：简单指令本地小模型消化；复杂任务（「帮我找一下那个红色的、上次出现过的包」）走 WiFi 上云端大模型。代价是延迟与断网可用性——Microduck 宣传卖点之一的「离线可用」，就是这条路的取舍结果。
  • 人格化层：让它「可爱」的不是 VLA 本体，而是外面包的一层「表情与动作风格库」——头部摆动频率、摇臀节奏、声音反馈，都是调好的预设动画，按情绪状态机触发。这层几乎不占算力，却是「萌」的全部来源。
高端餐厅开外卖分店：招牌菜（VLA 能力）要保留，但中央厨房（云端大模型）搬不过来，只能培训本地厨师（蒸馏小模型）做「简化版」；摆盘（人格化动画）则用预制模板保证水准稳定。顾客吃得开心，靠的不是每道菜都现做，而是「关键体验不缩水」。
延伸：「离线可用」与「云边协同」矛盾吗？

不矛盾，是「分级」：本地小模型兜底基础能力（走、避障、响应简单指令），保证断网不瘫；云端大模型处理真正需要「大知识」的请求。产品宣传「离线可用」时，通常指前者；上云是锦上添花而非必需。复刻时建议先做强本地兜底，再考虑云。

分步走完 Microduck 式 VLA 的一次完整请求
① 视觉采流 —— 头部相机抓取当前帧，预处理（缩放、归一化）后送入视觉编码器，得到视觉 token。
② 指令解析 —— 用户语音/文字指令经 ASR/分词转成文本 token，与视觉 token 拼合进 Transformer。
③ 动作生成 —— 小 VLA 模型自回归/扩散解码出未来 1–2 秒的关节目标轨迹（动作块）。
④ 风格包装 —— 人格化层按当前情绪状态，给轨迹叠加头部/躯干动画，注入「鸭子感」。
⑤ 底层执行 —— 轨迹切块、限幅后交给伺服环（第 06、08 课）以高频跟踪，同时持续回读 IMU/视觉，闭环修正。

Microduck 要保留「离线可用」卖点，其 VLA 架构最需要优先保证的是？

落地四板斧：蒸馏、降分辨率、云边分级、人格化包装。每一招都是「算力-功耗-体验」三角里的取舍。最后一章做总测验，收官「智能」模块。
