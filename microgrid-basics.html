微电网入门

什么是微电网

微电网就是一个「可自治的小电网」：自己发电、自己存电、自己用电，还能决定什么时候接入大电网、什么时候独立运行。

我们平时用的电，大多来自远方的大型发电厂，经过高压输电线路一路送到家里。这是一张覆盖全城、全国的大电网。而微电网（Microgrid）是其中的一个「小岛屿」：它由分布式电源（如屋顶光伏、小型风机，指分散在用户附近、规模较小的发电设备）、储能电池、用电负荷（指消耗电能的设备，如灯、空调）和一套控制装置组成，构成一个完整的小型电力系统。

它有两大本领：

  • 并网运行：通过一个叫 PCC（公共连接点，即微电网与主电网之间的"关口"开关所在的位置）的接口与大电网相连，互相买卖电。
  • 孤岛运行：当主电网出故障时，微电网可以快速断开连接，依靠自己的电源和储能继续给内部负荷供电——就像一艘船自带救生艇。
大学宿舍里你自己的插线板：上面插着台灯（负荷）、充电宝（储能）、或许还有个 USB 小风扇自发电（电源）。整栋楼的配电系统（主电网）停电时，只要你的充电宝还有电，你的台灯依然能亮——这就是一个小微电网的雏形。
一步步拼出微电网
① 负荷：先有用电需求——几栋楼、一个园区、一座海岛。
② 分布式电源：在负荷旁边装电源（光伏、风机），就地发电。
③ 储能：加上电池，把白天用不完的电存起来，供夜晚或阴天使用。
④ 控制装置：加上"大脑"，实时决定电从哪来、到哪去，以及何时与主电网连接或断开。
⑤ 完成：四要素齐备，一个能自治的小电网——微电网——就成立了。
微电网 = 分布式电源 + 储能 + 负荷 + 控制装置；判据只有一条——既能并网、又能孤岛独立运行。缺了"自治能力"，就只是普通的分布式发电而已。

为什么需要它

微电网的三大价值：让供电更可靠、让新能源就地消纳、让偏远地区用得上电。

价值一：提高供电可靠性

台风、暴雪、设备故障都可能让大电网停电。医院、数据中心一旦断电，后果严重。微电网能在主网故障的几十毫秒内切换到孤岛模式，继续供电——用户甚至察觉不到停电。

价值二：就地消纳新能源

太阳能、风能是"看天吃饭"的：中午光伏大发、夜里没了。如果直接把大量波动的新能源接入大电网，会给电网调度带来压力。微电网配上储能后，可以在本地把「发的不稳定的电」先存起来、再用掉，减轻对大电网的冲击——这就叫就地消纳。

价值三：为偏远地区供电

海岛、山区、牧区离大电网太远，拉一根高压线过去成本高得离谱。一个以"光伏 + 电池 + 柴油机备用"组成的微电网，就是更经济的选择。

整栋宿舍楼的配电系统是「大电网」：便宜、稳定，但一旦跳闸全楼都黑。你自己桌上的插线板 + 充电宝 + 小台灯是「微电网」：平时插上墙插（并网）跟着大楼用电，大楼停电时（孤岛）靠充电宝照样照亮你的桌面。你付出一点成本（买充电宝），换来的是「永不黑灯」的安心。

下面哪个场景最能体现微电网「提高供电可靠性」的价值？

「装了光伏板」不等于「有了微电网」。如果只并网发电、主网一停自己也跟着停，那只是一个分布式电源；只有具备独立运行（孤岛）能力，才算微电网。
记住三大价值的关键词：可靠（不停电）、消纳（新能源本地用）、偏远（没网也能用）。

两种运行状态

并网模式像小池塘连着大江，互通有无；孤岛模式像自带救生艇，主网故障时自己撑住一片天地。

并网模式（Grid-connected）

微电网通过 PCC 与主电网相连。电可以双向流动：自家光伏发电用不完时，余电卖给主网；阴天发电不足时，从主网购电。电压和频率由大电网"托底"，微电网里的电源只需跟随。

孤岛模式（Islanded）

当主电网故障（或计划检修）时，PCC 处的开关迅速断开，微电网进入孤岛模式。此时它必须独立维持电压和频率——这是最难的部分，通常由储能变流器或主电源来充当"顶梁柱"。

微电网的核心特征就是「无缝切换」：并网 ↔ 孤岛的转换要快、要稳，内部负荷几乎无感。行业里把这个切换开关叫 PCC（公共连接点），把负责指挥全过程的控制中心叫 MGCC（微电网中央控制器）。
动手试试：切换并网 / 孤岛，制造一次主电网故障
并网模式 = 小池塘通过水闸（PCC）连着大江：水多了放出去，水少了引进来。孤岛模式 = 关掉水闸自成一体：靠池塘里存的水（储能电池）和雨水（光伏）维持生态。主电网故障 = 大江突然干涸，有水闸都没用——所以真正救命的，是你自己存的「水」。

主电网发生故障时，微电网要保住自己的负荷，应该怎么做？

一句话总结：平时并网过日子（互通有无），出事孤岛靠自己（自治求生）。判断一个系统是不是真微电网，就看它孤岛时能不能撑住。

基本构成速览

微电网由四大件组成：分布式电源（发电）、储能（存电）、负荷（用电）、控制中枢 MGCC（指挥）。

第 1 章我们提到了四个要素，现在逐一认识它们的专业叫法。点击下面四张卡片翻面查看解释：

四大件 · 点击翻面
分布式电源
DG
Distributed Generation：安装在负荷附近的小型发电设备，如光伏板、小型风机、燃气轮机、柴油机。特点是就地发电、规模小、靠近用户。
储能
ESS
Energy Storage System：以电池为主（也有超级电容、飞轮），负责"削峰填谷"——电多时存、电少时放，也是孤岛运行时稳住电压频率的顶梁柱。
负荷
Load
微电网内部用电设备的总称：照明、空调、电机、充电桩等。设计微电网时，要先摸清负荷的用电量曲线和"哪些负荷绝不能断电"。
控制中枢
MGCC
Microgrid Central Controller：微电网的"大脑"。实时采集各设备的电压、电流、功率，决定何时并网/孤岛、电源发多少、储能充放多少。

这四大件里，MGCC 往往最容易被忽视。打个比方：电源和储能是"手脚"，负荷是"要干的活"，而 MGCC 是"大脑"——没有大脑，手脚再强壮也只是一盘散沙，无法在毫秒之间完成并网与孤岛的协调切换。

排序题：设计一座海岛微电网，合理的建设思考顺序是？
摸清负荷：先统计岛上每天要用多少电、哪些负荷最重要
配置电源：按负荷需求选光伏 / 风机 / 柴油机的容量
搭建控制：部署 MGCC，协调各设备运行与并网/孤岛切换
配置储能：按"无光无风时还能撑多久"来定电池容量

四大件口诀：发（DG）、存（ESS）、用（Load）、管（MGCC）。任何微电网项目，本质上都是围绕这四者做容量配置与控制策略设计。

典型应用场景

园区、海岛、数据中心、应急电源车——不同场景对微电网的诉求各不相同，但都离不开「自治」二字。

场景核心诉求典型配置对孤岛能力的依赖
产业园区降低用能成本、提升绿电比例屋顶光伏 + 储能 + 能量管理系统中：平时并网套利，停电时保底
海岛 / 偏远地区没有大电网可接，必须自给自足光伏 / 风机 + 大容量储能 + 柴油机备用极高：孤岛是常态而非应急
数据中心供电可靠性近乎 100%，断电即事故市电 + UPS + 柴油发电机 + 光伏储能高：切换速度要求毫秒级
应急电源车灾害现场快速恢复供电车载电池 / 柴油机，即停即用高：开到哪都是孤岛

可以看到，同样是微电网，「为什么要建」决定了「怎么建」：海岛的微电网以孤岛为常态，追求的是长期经济可靠；数据中心的微电网以孤岛为兜底，追求的是切换速度；园区的微电网更多在并网状态下做经济优化。

哪个场景对微电网的「孤岛能力」依赖最强、最需要长期稳定独立运行？

选场景看两件事：平时谁在供电（并网 or 自发自用）、断电代价有多大。代价越大、主网越弱，微电网的价值越突出。
四大场景的画像：园区要「省」，海岛要「自给」，数据中心要「稳」，应急车要「快」。判断场景需求，先问"断电一小时损失多少、主网可不可靠"。
