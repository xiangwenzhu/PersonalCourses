让脚落到你想要的点

走路听起来神秘，拆开看其实只有一件事：把脚按时序、按位置，放到地面的指定点上。关节角是因，脚的位置是果——这就是运动学要解的题。

上一课我们给鸭子装好了固件与实时循环（第 06 课）；这一课回到一个更朴素的问题：鸭子的腿，凭什么把脚放到「那里」？

第 02 课埋过一个伏笔：走路的每一步，都是「把支撑点按预定轨迹放到地面的指定位置」。现在把这句话拆开。所谓「指定的点」，在地面上是一个有坐标的位置——离身体多远、偏左还是偏右；而鸭子的腿，只有关节能听指挥——髋转多少度、膝弯多少度。所以走路的本质是一道翻译题：把「脚要去哪」翻译成「关节该转多少」。

你拿筷子夹菜时，大脑想的从来不是「手腕转 32 度、食指第二关节弯 15 度」——你想的是「筷子尖去夹那颗花生米」。但你的胳膊和手，只有关节能听指挥。大脑在暗中做翻译：目标位置 → 关节角度。机器鸭的「大脑」也要做同一道翻译，只是它不会含糊——必须算得又快又准。
核心定义：把「关节角度 → 脚的位置」算出来的过程叫正运动学；反过来，把「脚的目标位置 → 需要的关节角度」反解出来的过程叫逆运动学。走路控制器天天在用的，主要是后者。
点击卡片翻面：一句话分清两个方向
正运动学
已知：髋多少度、膝多少度。求：脚尖落在哪。方向是「角 → 位置」，像查表：每个姿态对应一个唯一的脚位置。
逆运动学
已知：脚尖要去哪。求：髋、膝各转多少度。方向是「位置 → 角」，是走路要反复求解的那道题。

填空：已知髋、膝两个关节角，算出脚尖坐标，这是 ；已知脚尖目标坐标，反解出髋、膝各转多少度，这是 。

一句话记住：正解是「给了角度问在哪」，逆解是「定了位置问转多少」。本课后面会亲手把这两个方向的公式都推一遍。

关节角与脚的位置

一条腿其实就是两根杆、两个铰链：髋角决定大腿摆向，膝角决定小腿相对大腿弯多少；两个角一组合，脚就被钉死在平面上的一个点。

把鸭子的腿抽象到最简：忽略脚的厚度、关节的复杂结构，它就是两根刚性杆 + 两个转轴——上面那根是大腿（连着髋），下面那根是小腿（连着膝），脚尖在最末端。这种「两根杆两个铰」的模型，在机器人学里有个标准名字：二连杆模型，它是所有双足腿动学的最小可学单元。

现在只做定性观察。把髋角固定，只动膝角：脚尖会绕着髋做圆周运动——因为小腿长度不变，膝角每变一点，脚尖就沿圆弧挪一点。把膝角固定，只动髋角：整个二连杆像钟摆一样绕髋转，脚尖走的是以髋为圆心、两腿总长为半径的大圆弧。两个角各自只能画圆，合起来才能钉住一个点——这就是为什么二维平面上的腿，最少需要两个关节。

拿两支笔首尾相接摆成折线：一支笔的末端连着另一支的起点，手指捏住连接点就是「膝」。只转下面那支，笔尖走小圆；只转上面那支，笔尖走大圆；两支一起转，笔尖可以够到平面上大片区域里的几乎任何一点。机器人腿的道理一模一样，只是它的「笔」是金属杆，「手指」是电机。
二维平面上，两个关节角恰好够、也只够钉住一个点：角度太少（一个关节）脚尖只能走圆弧，钉不住任意点；角度更多（三关节、四关节）则能钉住点之外还留有余地——这个「余地」后面叫冗余自由度。
点击卡片翻面：二连杆的四个关键词
连杆
把大腿、小腿各看成一根不会变形的刚性杆。杆的长度在模型里是常数，教学估算取大腿约 6 厘米、小腿约 6 厘米，以厂商规格书为准。
关节角
髋角：大腿相对竖直方向前倾多少；膝角：小腿相对大腿弯多少。两个角各管一段杆的方向，合成脚尖位置。
脚尖
二连杆的最末端，走路时要被「钉」到地面指定位置的那个点。位置用它在平面上的坐标（x, y）表示。
冗余
关节数多于钉住一个点所需的最小数目时，多出来的自由度。冗余有好处（避障、优化姿态）也有代价（逆解不唯一）。

在二维平面上，一条腿「想钉住一个点」最少需要几个关节？

二连杆 = 两根杆 + 两个角。两个角各画各的圆，合在一起才能把脚尖钉在点上。下一章给这套几何配上坐标系和公式。

坐标系与连杆

几何要变成公式，先立坐标系：以髋为原点、竖直向下为 x 轴、水平向前为 y 轴，两条连杆长度固定——有了这三个约定，脚尖位置就有了可以计算的名字。

「脚尖在哪」这句话太模糊，数学不认。要算它，先得给腿立一个坐标系——简单说就是：在哪量（原点）、朝哪量（坐标轴）、单位是什么。机器人学里有个习惯叫基座坐标系（base frame）：把原点放在腿的根部（对鸭腿就是髋关节中心），再规定两个互相垂直的方向作为轴。

本课用一套对鸭子特别顺手的约定：原点放在髋关节中心；x 轴竖直向下（站着不动时，腿正好沿 x 轴伸直）；y 轴水平向前（鸭子脸朝的方向为正）。这样腿伸直站立时，脚尖正好落在 x 轴正方向上，公式最干净。两只连杆的长度记为常数：大腿 $l_1$、小腿 $l_2$（教学估算各约 6 厘米，实际以厂商规格书为准）。

两个关节角也下个准确定义：髋角 $\theta_1$ 是大腿与 x 轴（竖直向下）之间的夹角，向前摆为正；膝角 $\theta_2$ 是小腿相对大腿的弯曲角——大腿方向已定，小腿再相对它转过 $\theta_2$。有了这套符号，「脚尖在哪」就变成了「给定 $l_1, l_2, \theta_1, \theta_2$，求坐标 $(x, y)$」——这正是下一章正运动学的输入。

坐标系就像给腿拍照前先摆正相机：站直、对齐、量好原点，照片里每个点的位置才有意义。摆歪了也能拍，但每个点的坐标都会跟着歪——后面所有公式都会背着这个「歪」走。
本课约定（记住即可，后面反复用）：原点 = 髋关节中心；x 轴 = 竖直向下；y 轴 = 水平向前；大腿长 $l_1$、小腿长 $l_2$；髋角 $\theta_1$、膝角 $\theta_2$。所有公式都在这套坐标下展开。

按本课约定，腿完全伸直站立时（两角都为 0），脚尖坐标约为 ，即落在 轴上。

坐标系是公式的地基：本课定了「髋为原点、竖直向下为 x、水平向前为 y」，连杆长度和关节角也有了符号。下一章用它们写出正运动学公式。

二连杆正运动学公式

正运动学就两行公式：脚尖的 x 坐标是两段杆竖直分量相加，y 坐标是水平分量相加——本质是把每段杆的投影拆到两根轴上再求和。

现在把「脚尖在哪」写成公式。思路分两步：先算大腿末端（也就是膝盖）在哪，再把小腿从膝盖处接上去。每一段杆在两个轴上的「贡献」，就是它长度乘以对应方向的三角函数——这是高中直角三角形的投影思想，机器人学只是给它套上了符号。

$$x = l_1\cos\theta_1 + l_2\cos(\theta_1 + \theta_2)$$

$$y = l_1\sin\theta_1 + l_2\sin(\theta_1 + \theta_2)$$

逐项拆开看：

  • $l_1\cos\theta_1$：大腿在 x 轴（竖直方向）上的投影长度。$\theta_1$ 越大，大腿越往前摆，竖直投影越短——这项随髋角变化。
  • $l_2\cos(\theta_1 + \theta_2)$：小腿在 x 轴上的投影。注意角度是两个角相加——因为膝角是「相对大腿」弯的，小腿的绝对方向等于大腿方向再加一个膝角。
  • 两个 y 项完全对称：把余弦换成正弦，就得到水平方向上的投影，相加即是脚尖的 y 坐标。
正运动学的本质：每段杆先按各自方向投影到 x 和 y 轴，再把同轴的分量加起来。形式简单，但它是逆运动学、雅可比、轨迹规划的地基——逆运动学就是从这里反解出来的。
像用两根手杖量地面上的一个点：先沿第一根手杖的方向走一段，记下竖直和水平各走了多少；再沿第二根的方向走一段，同样记下两个分量。把两次的竖直分量加起来、水平分量加起来，终点坐标就出来了。公式里的每一项，都是「沿某根杆走的那一小段」在两个方向上的分量。

正运动学公式里，小腿那一项为什么角度是「两个角相加」而不是单独的膝角？

取教学估算值 l1 = l2 = 6 厘米。当 θ1 = 0、θ2 = 0（腿伸直站立）时，x = 厘米，y = 厘米。

正运动学两行公式：x 把两段杆的竖直投影相加，y 把水平投影相加；小腿的角度是髋膝两角之和。有了它，就能从「腿摆成什么样」算出「脚在哪」。

二连杆逆运动学

逆运动学是从目标点反推关节角：先用余弦定理求出膝角，再反推髋角；同一个目标点往往有两种合法姿态——膝前弯还是膝后弯，可切换。

走路要的是逆方向：给定脚尖目标 $(x, y)$，求 $\theta_1, \theta_2$。好消息是二连杆有解析解（能写出闭式公式），不用数值搜索。推导分三步：

第一步：求膝角。把大腿和小腿、以及从髋到脚尖的连线看成一个三角形：三边分别是 $l_1$、$l_2$ 和 $d = \sqrt{x^2 + y^2}$（髋到脚尖的直线距离）。对这个三角形用余弦定理，就能解出膝角：

$$\theta_2 = \pm \arccos\!\left( \frac{x^2 + y^2 - l_1^2 - l_2^2}{2 l_1 l_2} \right)$$

注意正负号：$\theta_2$ 可以取正也可以取负，对应脚尖在膝盖的前侧还是后侧——这就是同一个目标点存在两种合法姿态的原因。实际鸭子有机械限位，通常只用其中一种。

第二步：求髋角。膝角定了之后，髋到脚尖的连线方向已知、三角形形状已知，用正弦定理或几何关系可推出：

$$\theta_1 = \operatorname{atan2}(y, x) \mp \arccos\!\left( \frac{x^2 + y^2 + l_1^2 - l_2^2}{2 l_1 \sqrt{x^2 + y^2}} \right)$$

其中 $\operatorname{atan2}(y, x)$ 是「髋到脚尖连线」相对 x 轴的方位角；第二项是这条连线与大腿之间的夹角。两项相减（或加，对应膝角的正负）就得到大腿的绝对方向。

第三步：检查可达性。反余弦的输入必须在 $-1$ 与 $1$ 之间——几何含义很直白：目标点到髋的距离 $d$ 必须满足「两边之和大于第三边、两边之差小于第三边」，也就是 $|l_1 - l_2| \le d \le l_1 + l_2$。超出这个范围，腿再努力也够不到，逆解不存在。

逆解实验台：拖动滑块设定脚尖目标，看二连杆如何反解与翻转

逆运动学就像已知绳长反推风筝姿态：线有多长（d）定了，两段骨架各多长（l1、l2）也定了，三角形形状就定了——但风筝可以在三角形里「肘朝前」或「肘朝后」两种摆法，这就是正负号对应的两组解。

目标点离髋太远，超出了 l1 + l2（两腿完全伸直也够不着），此时逆运动学会怎样？

逆解三板斧：余弦定理求膝角（带正负，两种姿态）、再反推髋角、最后验可达性。把滑块里的目标点拖出腿长范围试试，看红叉怎么告诉你「无解」。

雅可比与数值迭代

雅可比矩阵是「关节速度与脚速度的翻译官」；当腿更复杂、解析解写不出来时，数值迭代用「一小步一小步朝目标挪」的笨办法也能把逆解磨出来。

二连杆能写出闭式解，但真实机器人的腿往往更复杂——多一个踝关节、膝关节有偏置、连杆带夹角……解析公式会迅速变得又长又脆。这时工程师换一把工具：雅可比矩阵。它回答一个局部问题：关节角动一点点，脚尖会往哪动？

数学上，雅可比是脚坐标对关节角的偏导数排成的矩阵：

$$J = \begin{bmatrix} \dfrac{\partial x}{\partial \theta_1} & \dfrac{\partial x}{\partial \theta_2} \\[6pt] \dfrac{\partial y}{\partial \theta_1} & \dfrac{\partial y}{\partial \theta_2} \end{bmatrix}$$

它是个翻译官：给它一个「关节速度向量」，它输出「脚的速度向量」；反过来，想要脚以某个速度移动，可以解线性方程组反推关节该怎么动。当矩阵不可逆（腿完全伸直时）就进入奇异位形——这是机器人最怕的姿势之一，因为这时腿 lose 了某个方向的即时移动能力。

当解析逆解不存在或太复杂时，还有一条更朴素的路线：数值迭代。思路像盲人摸象找门：先随便摆一个姿势，算算脚尖离目标差多少；按雅可比告诉的方向微调关节角，让误差缩小一点；重复几十上百次，直到误差小到可接受。这就是机器学习里「梯度下降」的近亲——都是「朝减小误差的方向一小步一小步走」。

数值迭代就像用手柄微调投影仪画面：先按一下「左」，看图像往左偏了多少；再按「上」，再看；东按一下西按一下，几十次之后画面终于对齐。你没解过任何公式，但画面确实被「磨」到了位——雅可比告诉你「按这个键画面会往哪偏」，迭代就是反复利用这个信息。
两条路线各管一段：解析解快、准、可预测，适合二连杆这类简单结构；数值迭代慢半拍但万能，复杂腿、带约束、多冗余时都靠它。实际产品往往混用——能用解析就用解析，复杂工况 fallback 到迭代。

落脚点规划

关节会算了，还要算「脚该往哪踩」：步幅决定迈多远，抬脚高度决定越障能力，摆动轨迹决定落地是否平顺——落脚点还得避开支撑边界，否则下一步就是摔倒。

逆运动学解决「怎么把脚放到指定点」，但走路前还得先回答「指定点选在哪」。这一层叫落脚点规划，它把「我想向前走」翻译成一连串具体的地面坐标。三个参数最重要：

  • 步幅：相邻两步脚尖在前进方向上的距离。步幅太小走得慢、像碎步；太大则重心投影容易跑出支撑面，下一步就摔——后面第 08 课的 ZMP 判据会严格给出上限。
  • 抬脚高度：摆动相里脚尖离地的最大高度。要越过地毯边、线缆就得抬够高；抬太高又浪费能量、拉长单支撑时间，同样不稳。常见做法是按地形自适应，平路低抬、障碍高抬。
  • 摆动轨迹：从起点到终点，脚尖在空中走一条什么线。最朴素的是抛物线；更顺滑的做法是用贝塞尔曲线或多项式插值，保证起点、终点的速度和高度都连续，落地瞬间没有「砸地」感。

落脚点不是随便选的，有一个硬约束来自支撑多边形——脚掌接触点连成的凸多边形。走路时身体重心在地面的投影，要尽量留在支撑多边形内部；单脚支撑时支撑面骤减为一个脚掌的大小，此时新落脚点若离身体太远，重心就会被迫压到边界外。

最常见误区：把落脚点选得太靠近甚至超出可达域的远边界——腿绷直去够一个勉强的点，看似迈得大步子稳，实则进入奇异位形，控制和驱动都最吃力；一旦地面有微小起伏，脚尖落点偏移就会连锁放大成摔倒。复刻时给落脚点规划留「安全余量」：步幅宁小勿大，落点宁近勿远。
延伸：Microduck 的 15 个电机如何分配自由度？

官方未公开逐关节自由度的完整分配，教学估算：每条腿约 5 个自由度（髋 3、膝 1、踝 1），双臂共 4 个，颈部 1 个，合计 15。腿的五自由度让它在三维空间里不止能钉住脚尖位置，还能额外调整脚踝姿态和躯干朝向——这正是「冗余自由度」的价值：多出来的维度可以用来避障、优化能耗或让动作更拟人。

分步走一遍一个完整步态周期里的落脚点规划
① 定步幅与方向 —— 根据期望速度算出这一步的落点范围：想快则步幅大，但有上限；地面不平或转弯时主动收窄。
② 选抬脚高度 —— 扫描前方地形：有地毯边、线缆就抬高；平路就压低省能量。
③ 生成摆动轨迹 —— 用贝塞尔或多项式在「起点—终点」之间插值，保证起终点的速度与高度连续，落地不砸地。
④ 校验可达与安全 —— 用上一章的逆解检查目标点是否在可达域内、是否离奇异位形有足够余量；不满足就收缩步幅重来。
⑤ 执行并闭环修正 —— 摆动相里持续用视觉/IMU 修正轨迹，落地后进入支撑相，规划下一个落脚点。

为什么落脚点「宁近勿远、宁小勿大」是更稳的工程策略？

落脚点规划 = 步幅 + 抬脚高度 + 摆动轨迹 + 安全校验。参数选得保守一点，鸭子就稳一点；把「迈大步」的冲动留给仿真里验证过的场景。
