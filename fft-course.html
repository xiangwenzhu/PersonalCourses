快速傅里叶变换（FFT）

声音里的"配方"——什么是傅里叶变换

傅里叶变换就是把一个混合在一起的信号，拆解成一个个纯净的"单音"成分，告诉你每种成分占多少比例。

想象你喝到一杯好喝的混合果汁，想知道配方：是不是苹果汁多一点、橙汁少一点、还加了一点点柠檬？如果能把这杯果汁"拆解"回原始的几种果汁，并量出各自的比例，你就得到了这杯果汁的"配方"。

一段声音（比如一个和弦）其实是很多"纯音"叠加在一起的。傅里叶变换做的事情，就是把这个"混合声音"拆解成"哪些纯音、各自多响"的配方表——这张配方表就叫频谱，而"响度随纯音种类变化"的描述方式就是频域视角（相对地，原始的"声音随时间变化"的波形叫时域视角）。

为什么还需要"快速"

直接按定义拆解信号，计算量会随数据量的平方增长；FFT 是同一个答案的"抄近道"算法，又快又准。

直接按傅里叶变换的定义去计算（这种直接计算的版本叫 DFT，离散傅里叶变换），对于 N 个采样点，大约需要做 N×N 次运算——因为要分别检验每一个可能的频率，而检验每个频率又要扫一遍全部 N 个点。

这就像体检时，为了检查每两个人之间"谁认识谁"，你让每个人都和其他所有人握一次手确认——N 个人大概要握 N×N 次手。而快速傅里叶变换（FFT）的思路是：先把人分成两组，组内已经知道的关系可以直接复用，不需要每次都从头两两核对。数据量越大，这种"分组复用"省下的功夫就越多。

FFT 不是一种新的变换，它和 DFT 的结果完全一样，只是用了更聪明的计算顺序，把计算量从 $O(N^2)$ 降到了 $O(N\log N)$。当 N 是几百万时，这个差异可能是几小时和几毫秒的区别。

按定义直接计算 N 个点的离散傅里叶变换（DFT），大致需要多少次运算？

FFT 和 DFT 算出的结果完全相同，FFT 只是用分治的方式把 O(N²) 的计算量降到了 O(N log N)。

时域图告诉你"信号随时间怎么变化"；频域图（频谱）告诉你"信号由哪些频率、各多强的成分组成"。傅里叶变换就是从时域走到频域的那座桥；而逆傅里叶变换则是从频域走回时域。

复数与旋转：用欧拉公式描述频率

傅里叶变换内部用"复数旋转"来表示频率和相位；欧拉公式 $e^{i\theta}=\cos\theta+i\sin\theta$ 是理解这一切的钥匙。

为什么傅里叶变换的公式里总有一个 $e^{-i2\pi kn/N}$ 这样奇怪的东西？因为用"复数"来表示波，比单独用正弦、余弦函数更方便——一个复数 $e^{i\theta}$ 在复平面的单位圆上，就是"从角度 0 旋转了 $\theta$"。

欧拉公式：$e^{i\theta}=\cos\theta+i\sin\theta$。
把 $\theta$ 看成"转过的角度"，$e^{i\theta}$ 就是单位圆上转到对应角度的那个点。角度每增加一点，就相当于时间往前走了一点，而"转得快慢"正对应着"频率高低"。

乘以 $e^{i\theta}$ 相当于把一个复数逆时针旋转 $\theta$ 角，这个旋转角就是"相位"。

DFT 公式里的 $e^{-i2\pi kn/N}$，就是在问："如果有一个以频率 k 匀速旋转的参照波，我的信号在第 n 个采样点上，跟这个参照波对得上多少？"把所有点对出来的结果加起来，就是这个频率 k 上的强度，也就是频谱里第 k 根柱子的高度。

在复平面上，把一个复数乘以 $e^{i\theta}$，几何上相当于做了什么？

傅里叶变换用"旋转的参照波"去逐个比对信号，比对结果的强弱就是频谱；理解这一点的关键就是欧拉公式。

DFT 的定义与朴素计算

离散傅里叶变换（DFT）的公式看起来复杂，但拆开看，每一项都有清楚的含义。

对于 N 个采样点 $x_0, x_1, \dots, x_{N-1}$，第 k 个频率成分定义为：

$$X_k = \sum_{n=0}^{N-1} x_n \, e^{-i 2\pi k n / N}$$

其中：$x_n$ 是第 n 个采样点的值；$k$ 代表你正在检验的"第 k 种频率"；$e^{-i2\pi kn/N}$ 就是上一章说的"旋转参照波"在第 n 个点上转到的位置。把所有点的"信号值 × 参照波"加起来，就得到了这个频率上的强度 $X_k$。

以 N=4、信号 x=[1, 2, 3, 4] 为例，一步步算出 X₀ 和 X₁
第 1 步：计算 X₀（k=0）。此时 $e^{-i2\pi \cdot 0 \cdot n/4}=1$ 对所有 n 都成立，所以 $X_0 = 1+2+3+4 = 10$。X₀ 其实就是"直流分量"——所有采样点的总和（平均值的 N 倍）。
第 2 步：计算 X₁（k=1）。需要分别算出 n=0,1,2,3 时的 $e^{-i2\pi n/4}$：依次是 $1,\,-i,\,-1,\,i$。
第 3 步：把信号值乘上对应的旋转因子再相加：$X_1 = 1\cdot1 + 2\cdot(-i) + 3\cdot(-1) + 4\cdot i = (1-3) + (-2+4)i = -2+2i$。
第 4 步：对每个 k（k=0,1,2,3）都重复这个过程，就得到了完整的频谱 $X_0, X_1, X_2, X_3$。可以看到：每算一个 $X_k$ 都要扫一遍全部 N 个点，一共 N 个 k，所以总运算量是 $N\times N = N^2$。

DFT 公式本身不难，难的是它的朴素计算方式——N 种频率、每种都要扫 N 个点，共 O(N²) 次运算。

分治的魔法：把大问题拆成小问题

Cooley-Tukey FFT 算法的核心想法：把 N 个点按"下标的奇偶"分成两半，分别递归求解，再合并结果——这样省下了大量重复计算。

假设 N 是 2 的整数次幂。把信号按下标奇偶分成两组：偶数下标 $x_0, x_2, x_4,\dots$ 和奇数下标 $x_1, x_3, x_5,\dots$。神奇的是：N 点的 DFT，可以用这两组各 N/2 点的 DFT 结果拼出来，而不需要重新从头计算。

这就像拼图：与其每次都把一整幅 1000 片的拼图从零开始拼，不如先把它分成两堆 500 片，分别拼好，再把两幅"半成品"拼到一起——而这两堆 500 片，又可以继续各自分成两堆 250 片……一直分下去，直到每堆只剩 1 片（最简单情形）。

在真正做"蝶形运算"合并之前，Cooley-Tukey 算法通常会先把输入按"下标的二进制位反转"重新排列顺序，这样后续的分治合并才能原地、整齐地进行。下面的演示展示了 N=8 时，位反转前后下标顺序的变化：

分治三步：拆分（按奇偶）→ 递归（对半求解）→ 合并（蝶形运算）。这是 FFT 能加速的根本原因。

蝶形运算：加一下，减一下，再转个圈

合并两组子结果时，FFT 只需要一次"旋转 + 一次加法 + 一次减法"，这个基本操作因为图形像蝴蝶而被称为"蝶形运算"。

设偶数组的第 k 个结果是 $E_k$，奇数组的第 k 个结果是 $O_k$。合并时要用到"旋转因子"（twiddle factor）$W_N^k = e^{-i2\pi k/N}$，合并公式是：

$$X_k = E_k + W_N^k O_k \qquad\qquad X_{k+N/2} = E_k - W_N^k O_k$$

也就是说：先把 $O_k$ 旋转一个角度（乘以 $W_N^k$），再分别和 $E_k$ 做一次加法、一次减法，就同时得到了两个新的频率分量——这正是"一次计算，两份收获"，省下的功夫就是 FFT 比 DFT 快的来源。

复杂度为什么是 O(N log N)

每一层"拆分再合并"大约要做 O(N) 次运算，而数据能被对半拆分 $\log_2 N$ 层，所以总运算量是 $N \times \log_2 N$。

把 N 个点对半拆、再对半拆……直到每组只剩 1 个点，一共能拆 $\log_2 N$ 层（比如 N=8=2³，正好拆 3 层）。而每一层，不论分成了多少组，蝶形运算合并起来的总工作量都是 O(N)（每个点只参与一次加法和一次减法）。层数 × 每层的工作量，就是总复杂度：

$$O(N) \times \log_2 N = O(N\log N)$$

拖动滑块选择 N，比较朴素 DFT 与 FFT 的运算次数（对数坐标高度）

为什么必须要求 N 是 2 的幂才能这样对半拆？ 这里讲的"基 2（radix-2）Cooley-Tukey"算法要求 N 是 2 的幂，这样才能不断对半拆分、拆到剩 1 个点为止。如果 N 不是 2 的幂，还有其他变体（比如混合基 FFT、Bluestein 算法）可以处理任意长度的 N，只是实现更复杂一些，核心的分治思想是一致的。
FFT 之所以快，是因为用 $\log_2 N$ 层、每层 O(N) 的蝶形运算，替代了朴素算法里扫 N 遍、每遍 O(N) 的暴力比对。

FFT 在现实中的应用与边界

FFT 几乎无处不在：音频频谱分析、音视频与图像压缩、信号滤波、甚至大数乘法，都离不开它。

应用场景FFT 的作用
音乐软件 / 均衡器把声音拆成频谱，实时显示或调整各频段强弱
MP3 / JPEG 等压缩格式把信号变换到频域后，丢弃人耳/人眼不敏感的高频细节来压缩体积
数字滤波 / 降噪在频域里直接"削掉"不想要的频率成分，再变换回时域
大整数乘法 / 多项式乘法利用卷积定理，把原本 O(N²) 的乘法加速到 O(N log N)
常见误区：很多人以为"FFT 和 DFT 算出来的结果不一样，FFT 是近似算法"。这是错误的——FFT 只是 DFT 的一种快速计算方法，在理想精度下两者结果完全相同，FFT 并没有牺牲准确性来换取速度。
