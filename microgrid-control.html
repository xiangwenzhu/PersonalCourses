微电网运行模式与控制策略

控制的总体目标

微电网有两种运行模式：并网时「稳功率」，孤岛时「稳压稳频」——控制策略必须随模式切换。

微电网（Microgrid）是一组分布式电源（光伏、风电、储能、柴油机等）、负荷和监控保护装置的集合，可以在两种模式下运行：

  • 并网模式（Grid-connected）：通过公共连接点（PCC）接入大电网。大电网像一台「无穷大电源」，电压和频率由电网锚定，微电网只需按调度要求输出既定功率。
  • 孤岛模式（Islanded）：因故障或计划与大电网断开。此时微电网必须自己维持电压幅值和频率稳定，否则负荷无法正常工作。
并网是「跟着乐队演奏」——大电网是指挥，节奏（频率）和音高（电压）都有人定，你只需要把自己的声部（功率）演奏好；孤岛是「自己当指挥」——乐队散了，你得自己打拍子、定音高，还得让每件乐器（各台电源）配合好。

控制策略没有「万能的一种」，只有「适配当前模式的一种」。后面四章分别讲并网用的 PQ 控制、孤岛用的 V/f 控制、两者都能用的下垂控制，以及把它们串起来的主从/对等架构与无缝切换。
记住一句话：并网稳功率，孤岛稳压稳频。这是全部微电网控制逻辑的出发点。

并网控制：恒功率 PQ 控制

并网时逆变器当「电流源」：按上层 EMS 下发的 $P_{ref}$、$Q_{ref}$ 输出固定有功和无功，电压频率交给大电网。

PQ 控制（恒功率控制）把逆变器等效为一个可编程的电流源。由于大电网刚性很强（电压幅值 $V$、频率 $f$ 基本不动），逆变器只需控制注入电流的相位和幅值，就能决定送出多少有功和无功：

$$P = P_{ref}, \qquad Q = Q_{ref}$$

其中：$P_{ref}$ 为上层能量管理系统（EMS）下发的有功指令（如光伏按最大功率点跟踪 MPPT 输出、储能按充放电计划执行）；$Q_{ref}$ 为无功指令（可用于功率因数校正或电压调节）。

PQ 控制的工作原理

分步揭示：从采样到输出
① 采样：测量逆变器输出三相电压、电流，经坐标变换（dq 变换）得到 $v_d, v_q, i_d, i_q$。
② 计算实际功率：由 dq 分量算出瞬时有功 $P = \frac{3}{2}(v_d i_d + v_q i_q)$、无功 $Q = \frac{3}{2}(v_q i_d - v_d i_q)$。
③ 功率外环：$P$ 与 $P_{ref}$ 比较、$Q$ 与 $Q_{ref}$ 比较，各经一个 PI 控制器，生成电流内环的参考值 $i_d^{ref}, i_q^{ref}$。
④ 电流内环：快速跟踪电流参考，产生 PWM 驱动信号，控制功率器件的通断。
⑤ 结果：无论电网电压如何微小波动，逆变器输出的 $P, Q$ 始终锁定在指令值——这就是「恒功率」。
PQ 控制的前提是「有大电网兜底」。如果大电网断开（孤岛），而逆变器仍死磕 $P_{ref}$、$Q_{ref}$，电压和频率将失去支撑而崩溃——所以孤岛瞬间必须立即切换控制策略。

PQ 控制中，$P_{ref}$ 和 $Q_{ref}$ 通常由谁给出？

PQ 控制 = 功率外环 + 电流内环的双环结构；本质是「跟电网同步、按指令出力」。$P_{ref}$ 常来自 MPPT 或经济调度，$Q_{ref}$ 用于无功/电压支撑。

孤岛控制：恒压恒频 V/f 控制

孤岛时必须有一台「主控电源」用 V/f 控制建立电压和频率基准：$V = V_{ref}$、$f = f_{ref}$，其他电源跟随它。

孤岛后，微电网内不再有无穷大电源。根据基尔霍夫定律，任一时刻电源发出的功率必须等于负荷消耗的功率——而功率平衡是靠「电压频率这个信号」间接实现的。V/f 控制把主控逆变器（通常接储能）等效为「电压源」：

$$V = V_{ref}, \qquad f = f_{ref}$$

其中：$V_{ref}$ 为额定电压幅值参考（如 380 V 线电压），$f_{ref}$ 为额定频率参考（如 50 Hz）。主控电源负责硬扛功率缺额：负荷增加导致电压/频率下跌 → 主控增大输出 → 把它们拉回额定值。

其他分布式电源（如光伏）在孤岛下一般不参与调压调频，而是按主控电源建立的电压频率信号，以 PQ 或限功率方式跟随出力。

主控电源像乐队里的定音鼓手：它先给出节拍（频率）和基准音高（电压），其他乐手听着它演奏。定音鼓手要是走神（退出），整场演出就散了——所以主控电源必须时刻在线，且容量要足够大。

孤岛模式下，由谁负责建立电压和频率的基准？

V/f 控制是「主从架构」：主控电源单点承担全部调节压力，容量不足或过载时系统仍会失稳。多台电源想用 V/f 直接并联会因「各自为政的电压源并联」产生环流——这正是下一章下垂控制要解决的问题。
V/f 控制的本质是「电压源外特性 + 恒压恒频闭环」；适用场景：孤岛运行、主控电源、容量较小的微电网。

下垂控制 Droop

下垂控制模仿同步发电机的「有功不可就频率、无功不可就电压」特性：$f = f_0 - k_p(P - P_0)$、$V = V_0 - k_q(Q - Q_0)$，让多台逆变器无需通信就能并联均分负荷。

传统同步发电机有一个天然的稳定机制：负荷增加 → 转子减速 → 频率下降 → 调速器加大油门 → 各机组按下垂系数自动多出力。逆变器没有转子，但可以编程模拟这条特性：

$$f = f_0 - k_p\,(P - P_0)$$ $$V = V_0 - k_q\,(Q - Q_0)$$

各符号含义：$f$ 为逆变器输出频率；$f_0$ 为空载频率（$P = P_0$ 时的频率，常取额定 50 Hz）；$k_p$ 为有功-频率下垂系数（Hz/kW），越大表示「同样的出力增加，频率让得越多」；$P$ 为实际输出有功；$P_0$ 为功率基点；$V, V_0, k_q, Q, Q_0$ 在无功-电压通道上含义对应。

并联运行时，所有逆变器共享同一个母线频率 $f$。由 $f = f_0 - k_{p1} P_1 = f_0 - k_{p2} P_2$ 可得：

$$k_{p1} P_1 = k_{p2} P_2 \;\Rightarrow\; \frac{P_1}{P_2} = \frac{k_{p2}}{k_{p1}}$$

即出力与下垂系数成反比：两台额定相同的逆变器取相同 $k_p$，负荷自然均分——全程不需要任何通信线。

两台额定容量相同的逆变器并联，采用下垂控制，$k_{p1} = 2\,k_{p2}$。负荷均分时，二者出力之比 $P_1 : P_2$ 为？

下垂控制的代价是稳态频率偏差：负荷越重，$f$ 离 $f_0$ 越远（频率跌落 $\Delta f = k_p \cdot P$）。工程上常用「下垂 + 二次调频」补偿偏差，或与传统同步机混合运行时借助其惯量。
下垂控制三要素：模仿同步机的 $P$-$f$、$Q$-$V$ 特性；按 $1/k_p$ 反比分配负荷；完全无通信、即插即用。它是微电网多机并联的基石。

主从控制与对等控制

多电源协同有两大家族：主从控制（一台主逆变器定基准、其余跟随）与对等控制（全部下垂、地位平等）。

主从控制（Master-Slave）

一台主逆变器（通常接储能）孤岛时切换为 V/f 控制建立电压频率基准；其余从逆变器维持 PQ 控制，按主逆变器给的参考出力。结构简单、电压频率质量高，但主逆变器是单点瓶颈，切换依赖通信。

对等控制（Peer-to-Peer）

所有逆变器都采用下垂控制，无主无从、地位完全对等，即插即用、冗余度高；代价是存在稳态电压/频率偏差，且线路阻抗不均时会破坏均流精度。

无缝切换

微电网要在「并网 ↔ 孤岛」之间平稳过渡：计划孤岛可提前预同步，非计划孤岛则考验控制的快速性与鲁棒性。

STS 与预同步

静态切换开关（STS）负责在公共连接点快速合闸/分闸。重新并网时，若微电网侧与大电网侧的电压幅值、频率、相位不一致就合闸，会产生巨大的冲击电流（类似把两台相位不同的发电机硬并联）。因此合闸前必须通过预同步控制，把两侧「对齐」。

排序题：并网前的预同步检查顺序（用 ↑ ↓ 调整）
① 检测电压幅值差 $\Delta V$（是否在允许范围内）
② 检测频率差 $\Delta f$（是否满足滑差要求）
③ 检测相位差 $\Delta \varphi$（等待同期点，越接近 0° 越好）
④ 条件满足，STS 合闸并网

提示：工程实践中三者会同时监视，但「先确认幅值差和频率差在窗口内 → 再捕捉相位过零点合闸」是标准的同期逻辑顺序。

非计划孤岛的最大危害是「不可控」：功率缺额瞬间由微电网内电源硬扛，频率电压可能瞬间越限；若检测延迟，还可能出现非计划孤岛带故障运行，危及检修人员与设备。反孤岛保护（如主动频率偏移法）正是为此而设。
无缝切换 = 快速可靠的孤岛检测 + 恰当的 STS + 并网前预同步（幅值→频率→相位对齐）。三者缺一，切换就会有冲击。
