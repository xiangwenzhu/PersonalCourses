单细胞转录组分析：解锁细胞异质性

什么是单细胞 RNA-seq

Bulk RNA-seq 测的是一群细胞的"平均表达"，单细胞 RNA-seq（scRNA-seq）逐个细胞测量，能发现被平均值掩盖的稀有细胞类型和细胞状态。

人体约有 37 万亿个细胞。Bulk RNA-seq 把一块组织里所有细胞的 RNA 混在一起测序，得到的每个基因表达量是"平均数"：

$$\bar{x}_g = \frac{1}{N}\sum_{i=1}^{N} x_{g,i}$$

如果某种关键细胞只占组织的 1%，它的表达信号会被 99% 的其他细胞稀释到几乎看不见。scRNA-seq 的思路很直接：把每个细胞单独装进一个"反应室"，各自测各自的。

Bulk 像把一整篮水果打成一杯混合果汁——你能尝出"有点苹果味、有点香蕉味"，但不知道篮子里到底有几种水果、各有多少。单细胞像把水果一颗颗拿出来看：3 个苹果、2 根香蕉、还有 1 颗你从没见过的稀有水果。

核心概念速览

点击卡片，记住 4 个核心概念
细胞异质性
同一组织里不同细胞的基因表达千差万别。肿瘤里既有癌细胞也有免疫细胞、基质细胞——bulk 把它们混为一谈。
稀有细胞类型
如血液中的树突状细胞（<1%）。单细胞能捕捉它们；bulk 中它们的信号被淹没在平均值里。
Dropout
单细胞数据大量为 0：不是基因没表达，而是 RNA 量太少没测到。这是 scRNA-seq 最主要的噪音来源。
细胞通量
一次实验能测多少细胞。10x Genomics 一次可测上万到几十万细胞，成本远低于传统手工分选。
Bulk vs 单细胞：拖动滑块改变稀有细胞比例，看平均值如何"掩盖"差异

单细胞革命性的地方不在于测得更"准"，而在于测得更"细"——把组织拆解成细胞类型的拼图，而非一张模糊的合影。

Bulk RNA-seq 分析肿瘤组织时，最大的局限是什么？

记住一句话：Bulk 问"这个组织平均表达什么"，单细胞问"每种细胞各自表达什么"。下一章看单细胞实验是怎么做到的。

实验流程：从组织到表达矩阵

组织解离成单细胞悬液 → 微流控液滴包裹（一细胞一液滴）→ 液滴内反转录并打上条形码 → 建库测序 → cellranger 输出"基因 × 细胞"表达矩阵。

单细胞实验的核心工程挑战是：如何在一台测序仪上同时测几万个细胞，还能分清哪条 read 来自哪个细胞？答案是"液滴 + 条形码"：每个细胞和一个带唯一条形码的凝胶珠（GEM）一起被包裹在油包水的微滴里，在液滴内完成 RNA 捕获和反转录。

动手排一排：10x 单细胞实验的正确顺序
细胞悬液与凝胶珠在微流控芯片上形成液滴
组织解离 + 细胞活性检测（活细胞 >80%）
cellranger count 输出表达矩阵
液滴内裂解细胞、捕获 mRNA 并反转录（带 barcode + UMI）
文库构建（打断、加测序接头、PCR 扩增）
上机测序（NovaSeq，PE150）

双条形码：cell barcode 与 UMI

每条 read 携带两段关键信息：

  • Cell barcode：标识这条 read 来自哪个细胞（每个凝胶珠一个码）
  • UMI（Unique Molecular Identifier）：标识它来自哪个原始 mRNA 分子，用于去除 PCR 扩增重复
# cellranger 一步完成比对、定量、细胞识别
cellranger count --id=sample1 \
  --transcriptome=refdata-gex-GRCh38-2020-A \
  --fastqs=./fastqs \
  --sample=sample1 \
  --expect-cells=10000
条形码像快递单号：cell barcode 告诉你包裹（细胞）寄件人是谁，UMI 告诉你包裹里每件商品（mRNA 分子）的唯一编号——即使商家复印了十份发货单（PCR 扩增），按编号也只算一件。

UMI（Unique Molecular Identifier）的主要作用是什么？

液滴微流控 + 双条形码是高通量单细胞的技术基石。理解了"一细胞一码、一分子一号"，下游所有数据结构就顺理成章了。

数据结构：稀疏矩阵与 Seurat 对象

scRNA-seq 的核心数据是"基因 × 细胞"的表达矩阵（通常 2 万+ 基因 × 1 万+ 细胞），其中超过 90% 的元素是 0——所以用稀疏格式存储，在 R 里装进 Seurat 对象统一管理。

cellranger 的输出

文件/目录内容
filtered_feature_bc_matrix/过滤后的表达矩阵（barcodes.tsv + features.tsv + matrix.mtx）
raw_feature_bc_matrix/未过滤矩阵（含空液滴/环境 RNA，背景噪音高）
web_summary.html关键指标：测到的细胞数、每细胞中位 UMI、测序饱和度
cloupe.cloupeLoupe 浏览器文件，可视化预分群结果

MTX 格式只存非零值（行号, 列号, 值），把 2 万 × 1 万的稠密矩阵压缩到几十分之一：

%%MatrixMarket matrix coordinate integer general

1 1 14
7 1 3

稀疏矩阵长什么样：拖动滑块过滤低计数，体会"90% 是零"

Seurat 对象：R 里的"集装箱"

Seurat 是单细胞分析最主流的 R 包。它的对象把表达矩阵、细胞元数据（质控指标、样本来源）、降维结果（PCA/UMAP 坐标）、聚类标签、marker 基因表全部装进一个结构：

# Seurat v5 对象的核心槽位
obj@assays$RNA$counts  # 原始 count 矩阵（稀疏）
obj@meta.data          # 每个细胞的元数据：nCount_RNA, nFeature_RNA, percent.mt
obj@reductions$pca     # PCA 坐标
obj@reductions$umap    # UMAP 坐标
obj$seurat_clusters    # 聚类标签
Seurat 对象像一个多功能收纳箱：表达矩阵是"货物"，元数据是"标签贴"，降维结果是"折叠好的地图"，聚类标签是"分拣格"。所有后续分析都在这个箱子里进行。

为什么单细胞表达矩阵要用稀疏格式（如 MTX）存储？

记住三个词：稀疏矩阵（怎么存）、cellranger（怎么产生）、Seurat 对象（怎么用）。下一章解决一个现实问题：测出来的细胞并不都是"好细胞"。

质控与过滤：剔除"坏细胞"

不是所有"条形码"都代表完整细胞：死/濒死细胞线粒体基因比例高，空液滴基因数极低，两个细胞共用一个液滴形成 doublet。质控就是设阈值把它们过滤掉。

三大质控指标

  • 线粒体基因比例（percent.mt）：细胞膜破裂后细胞质 RNA 流失，线粒体 RNA 残留 → 比例高 = 细胞受伤或已死。通常阈值 10%–20%
  • 检测到的基因数（nFeature）：过低（<200）多为空液滴或碎片；过高（>5000–6000，视组织而定）疑似 doublet
  • doublet 检测：一个液滴混入两个细胞，表达量异常高且基因谱"像两种细胞的混合"。用 DoubletFinder / Scrublet 算法打分

线粒体比例的计算公式：

$$\text{percent.mt} = \frac{\sum \text{线粒体基因 UMI}}{\sum \text{全部基因 UMI}} \times 100\%$$

质控阈值实验：拖动两个滑块，看保留多少细胞

不要把阈值当成绝对真理！不同组织、不同解离方案的"正常"线粒体比例差异很大（如心肌、肝脏天然偏高）。阈值要看分布（小提琴图/散点图），而不是照搬默认值。
质控是"双向"的：过滤太松 → 死细胞/doublet 污染下游聚类；过滤太狠 → 丢掉真实的高代谢或脆弱细胞类型（如某些神经元、浆细胞）。

某细胞的线粒体基因比例高达 45%，最可能的原因是什么？

质控的目标是"让进入分析的每个点都尽量是一个完整、活着的细胞"。阈值服务于这个目标，而不是反过来。下一章进入最激动人心的一步：给上万细胞分群。

降维与聚类：给细胞分群

2 万维的基因表达无法直接观察。流程：选高变基因 → PCA 降到 30–50 维 → 建 KNN 邻接图 → Louvain/Leiden 聚类 → UMAP 画成 2D 图 → 用 marker 基因给每群命名。

Seurat 标准聚类流程（点"下一步"逐步展开）
① FindVariableFeatures：挑出 2000 个"在不同细胞间波动最大"的高变基因，去掉所有细胞都恒定表达的"管家噪音"。
② ScaleData + RunPCA：标准化后做 PCA，取前 30–50 个主成分。每个 PC 是一个"表达模式的方向"，保留它既降噪又压缩。
③ FindNeighbors + FindClusters：在 PC 空间里找每个细胞的 K 个最近邻居，连成图后用 Leiden/Louvain 算法把图切成"社群"，即细胞簇。分辨率参数控制簇的粗细。
④ RunUMAP + 注释：UMAP 把高维结构压到 2D 供人眼观察；然后用已知 marker 基因（如 CD3E=T 细胞，MS4A1=B 细胞）给每个簇写上生物学名字。
聚类像给图书馆新书分架：先看每本书的"主题关键词"（高变基因），把相似的书摆到一起（KNN 图 + Leiden 切分），最后给每个书架贴标签（marker 基因注释）。UMAP 只是"楼层导览图"，方便人逛，书的真实位置在高维空间里。
降维聚类模拟：点"运行 UMAP"，看高维细胞如何投影成 2D 并分成 3 簇

marker 基因鉴定

用 FindAllMarkers 对每个簇做"本簇 vs 其他所有簇"的差异检验（Wilcoxon 秩和），找出每个簇特异性高表达的基因，对照已知文献命名：

Marker 基因对应细胞类型
CD3D / CD3ET 细胞
MS4A1 / CD79AB 细胞
LYZ / S100A8单核/髓系细胞
NKG7 / GNLYNK / 细胞毒性淋巴细胞
Leiden/Louvain 的"分辨率"参数是聚类的总开关：调大 → 簇变多变细；调小 → 簇合并变粗。没有唯一正确值，取决于你的生物学问题。

在聚类流程中，PCA 和 UMAP 各自的角色是什么？

走完这章你就掌握了单细胞分析的主干：质控 → 归一化 → PCA → 聚类 → 注释。剩下的是在这个骨架上长出更高级的分析。

高级分析：轨迹、互作与整合

分群只是起点。高级分析回答更深的问题：细胞如何沿时间分化（轨迹推断/pseudotime）、细胞之间如何"对话"（配体-受体互作）、如何联合多种组学（多组学整合）。

三大高级方向

问题方法代表工具
细胞如何随时间分化？轨迹推断 + 拟时序（pseudotime）Monocle3 / Slingshot / scVelo（RNA 速率）
哪些细胞在互相"对话"？配体-受体互作分析CellPhoneDB / CellChat / NicheNet

拟时序（pseudotime）的原理是什么？

单细胞转录组是"静态快照"，但细胞状态构成一条连续的分化轨迹。轨迹推断把高维表达空间拟合成一条树状流形（manifold），再计算每个细胞沿树的"距离"作为伪时间：

$$\text{pseudotime}(c_i) = \text{沿轨迹从根节点到细胞 } c_i \text{ 的测地距离}$$

配合 RNA 速率（scVelo 用未剪接/已剪接 mRNA 比例推断转录动态方向）可以判断"细胞正往哪走"，而不仅停留在哪。找分支点上差异表达的基因，就能锁定驱动分化的关键调控因子。

轨迹推断像看一张全班合影推断每个人的成长历程：虽然只拍了一瞬间，但有人戴乳牙、有人戴牙套、有人戴假牙——把"状态"排成序，就还原出了"时间"。配体-受体分析则像分析谁在给谁递纸条（配体=纸条，受体=接收的手）。
CellPhoneDB 的逻辑：某对配体-受体基因在 A 群高表达、其对应受体/配体在 B 群高表达，就推断"A 可能在向 B 发信号"。统计检验比较真实细胞群组合 vs 随机置换，排除"表达高只是偶然"。

多组学整合：一个细胞，多个侧面

10x Multiome 可同时测同一细胞的 RNA 和 ATAC（染色质开放性）；CITE-seq 加测表面蛋白（ADT）。整合的难点是模态间的批次与量纲差异，常用加权最近邻（WNN）为每个细胞在每种模态找邻居再融合：

# Seurat v5：加权最近邻整合 RNA + ATAC
obj <- FindMultiModalNeighbors(obj,
  reduction.list = list("pca", "lsi"),
  dims.list = list(1:30, 2:40))
高级分析的花样越多，假阳性的陷阱越多。细胞互作分析的配体-受体对是"表达共现"，并不等于真实的生物学通讯——必须用实验（如受体阻断、空间转录组共定位）验证。
