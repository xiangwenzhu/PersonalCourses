生信文件格式完全指南：FASTA 到 VCF

文件格式：生信的通用语言

生信不是"看图片"，是"读文本"。六大格式（FASTA/FASTQ/SAM/BAM/VCF/GFF）就是这门领域的通用语言，全都能用记事本打开。

所有生信数据的本质都是纯文本。程序之间靠约定的"排版规则"互相理解：哪里是标题、哪里是数据、每列什么意思。掌握这些规则，你就能在没有专业软件的情况下，用 grep、awk 直接"透视"任何文件。

文件格式像各国的公文格式：FASTA 是"名片"（只有姓名和一句话介绍），FASTQ 是"体检报告"（还带评分），SAM 是"考勤表"（谁在哪做了什么），VCF 是"差异清单"（和模板比哪里不一样），GFF 是"地图"（每条街有什么建筑）。
点击卡片，快速认识六大格式
FASTA
以 > 开头的标识行 + 序列行。存储 DNA/RNA/蛋白质序列，最基础、最通用。
FASTQ
4 行 = 1 条 read（序列 + 质量值）。高通量测序的原始输出格式。
SAM/BAM
存储 reads 比对到参考基因组的结果。SAM 是人类可读文本，BAM 是它的二进制压缩版。
VCF
Variant Call Format：记录样本与参考基因组差异（SNP/Indel）的清单。
GFF/GTF
基因组注释文件：标出每条染色体上基因、外显子、CDS 的位置坐标。

下列哪种格式是二进制文件，不能直接拿记事本打开？

记住这个口诀："序列用 FA，测序用 FQ，比对看 SAM，变异写 VCF，注释查 GFF"。后面逐一深入。

FASTA 与 FASTQ：序列的两种形态

FASTA 是"光秃秃的序列"（只有字母），FASTQ 是"带质量评分的序列"（字母 + 打分）——高通量测序离不开 FASTQ。

FASTA：两行长这样

>sp|P69905|HBA_HUMAN Hemoglobin subunit alpha
MVLSPADKTNVKAAWGKVGAHAGEYGAEALERMFLSFPTTKTYFPHFDLSHGSAQVKGHG
KKVADALTNAVAHVDDMPNALSALSDLHAHKLRVDPVNFKLLSHCLLVTLAAHLPAEFTP
AVHASLDKFLASVSTVLTSKYR
  • > 开头是标识行：ID + 描述
  • 接下来是序列行，通常每行 60/80 字符，可换行

FASTQ：四行长这样

@SEQ_ID_001
GATTTGGGGTTCAAAGCAGTATCGATCAAATAGTAAATCCATTTGTTCAACTCACAGTTT
+
!''*((((***+))%%%++)(%%%%).1***-+*''))**55CCF>>>>>>CCCCCCC65
FASTA 是"只写答案的考卷"，FASTQ 是"带老师评分的考卷"。每 4 行一组：名字、答案（序列）、加号、评分（质量值）。评分用 ASCII 字符表示，字符越靠后（如 I），质量越高。
FASTQ 解码器：点击一条 read，逐行拆解它的结构

质量字符 ASCII 码 - 33 = Phred 质量值。字符 I（ASCII 73）→ Q40（万分之一错误率），!（ASCII 33）→ Q0（100% 错误率）。

FASTQ 文件第 4 行的字符 I 代表什么？

会读 FASTQ = 会看测序数据的"出生证明"。下一章：比对结果怎么存。

SAM/BAM：比对结果的账本

SAM 把每条 read"落到"参考基因组的坐标上：哪个染色体、哪个位置、正链还是反链、比对质量如何——11 列一目了然。

比对工具（BWA、Bowtie2）输出 SAM 文件，记录每条 read 的"落点"。一个典型 SAM 行：

read001  0  chr1  10001  60  75M  *  0  0  GATTTGGGGTTCAAAGC...  !''*((((***+))%%...  NM:i:2  AS:i:70
列字段名含义例子
1QNAMEread 名字read001
2FLAG位标志（单端/双端/反向/重复…）0=正向唯一比对
3RNAME比对到的染色体chr1
4POS起始位置（1-based）10001
5MAPQ比对质量（0-60，越高越可信）60
6CIGAR比对操作串75M=75 个匹配
7-9RNEXT/PNEXT/TLEN双端另一头信息* 表示单端
10SEQread 序列GATTTG…
11QUAL质量值!''*((…
SAM 像快递单：谁寄的（QNAME）、寄到哪（RNAME+POS）、包裹完不完整（CIGAR）、签收人可信度（MAPQ）。
SAM 列查看器：鼠标悬停（或点击）高亮每一列的含义

CIGAR：比对的"操作符"

符号含义场景
MMatch/_MISMATCH（对齐上）正常比对
IInsertion（read 多了）测序插入或真实 Indel
DDeletion（read 少了）真实缺失
SSoft clip（两端没比对上）接头残留
NSkip（跳过一大段）RNA-seq 跨内含子
FLAG 是"位掩码"：99 = 双端正向 + 配对成功 + 第一条。别背，用 samtools flagstat 或在线解码器查。

一条 RNA-seq read 的 CIGAR 是 50M2000N25M，说明什么？

SAM 是人类可读，BAM 是机器友好。两者信息等价，用 samtools 互转：samtools view -bS in.sam > out.bam。

VCF：变异清单的标准写法

VCF 记录"样本和参考基因组哪里不一样"：前 5 列定位置（染色体/位置/ID/参考碱基/变异碱基），INFO 列塞满注释。

##fileformat=VCFv4.2
##source=GATK
#CHROM  POS     ID      REF     ALT     QUAL    FILTER  INFO
chr1    10001   rs123   A       G       99      PASS    DP=35;AF=0.5
chr1    10520   .       C       T       50      q10     DP=12;AF=0.33
chr2    20000   rs456   G       A       95      PASS    DP=48;AF=1.0
  • CHROM/POS：变异位置
  • REF/ALT：参考基因组碱基 / 样本中发现的碱基
  • QUAL/FILTER：质量值 / 是否通过过滤（PASS 才是可信的）
  • INFO：深度 DP、等位基因频率 AF、功能注释（SIFT/ClinVar）等
VCF 行解析器：拖动滑块，逐字段高亮解读

AF（Allele Frequency）= 变异等位基因比例：0.5 是杂合，1.0 是纯合。肿瘤样本里 AF 0.3 可能意味着只有部分细胞带这个突变（异质性）。

VCF 中某变异 REF=A, ALT=G, AF=1.0，说明该样本在这个位点是？

看到 FILTER 不是 PASS 的行，默认先当噪音。这是变异分析的第一道闸。

GFF/GTF：基因组的地图

GFF/GTF 是注释文件：用 9 列坐标标出"这条染色体上，从哪到哪是一个基因/外显子/CDS"，是定量分析和变异注释的基础。

chr1  .  gene         11874  14409  .  +  .  ID=gene1;Name=DDX11L1
chr1  .  mRNA         11874  14409  .  +  .  ID=tx1;Parent=gene1
chr1  .  exon         11874  12227  .  +  .  Parent=tx1
chr1  .  exon         12613  12721  .  +  .  Parent=tx1
chr1  .  CDS          12020  12090  .  +  0  Parent=tx1
列含义生信关注点
1染色体chr1 / 1 / NC_000001.11（注意命名差异）
3特征类型gene / mRNA / exon / CDS / UTR
4-5起止坐标1-based 闭区间（和 BED 的 0-based 半开不同！）
7链方向+ 正链 / - 反链
9属性ID、Parent、Name、biotype
坐标系统最容易踩坑：GFF/VCF 是 1-based，BED 是 0-based 半开。同一个位点写进不同文件，数字可能差 1！
坐标陷阱：同一段序列在 GFF 和 BED 里的数字差异

GFF 像门牌号从 1 开始数（1-based），BED 像数组下标从 0 开始数（0-based）。同一栋楼，两种叫法差 1 号。写脚本时如果没对齐，注释就全错位了。

一个基因在 GFF 里是 start=100, end=200，转成 BED 格式应该是？

记住：GFF/VCF 从 1 数，BED 从 0 数且右端不包。liftOver 或格式转换时先想清楚坐标系。

综合实战：不用软件，徒手解析所有格式

给你任意生信文件，30 秒内判断格式、提取关键信息、发现异常——这是生信工程师的"肌肉记忆"。

文件格式识别流程

打开一个陌生文件，按这个顺序判断
① 看首字符：> 开头 → FASTA；@ 开头且第 3 行是 + → FASTQ；数字/字母+tab → 可能是 SAM/GFF/BED。
② 数列数：11 列且有 FLAG/MAPQ → SAM；9 列且有 gene/exon → GFF/GTF；5 列数字区间 → BED。
③ 看表头注释：##fileformat=VCF → VCF；@HD/@SQ/@PG → SAM header。
④ 查后缀：.gz 先 zcat 或 gunzip -c；.bam/.vcf.gz 用 samtools/bcftools，别直接 cat。
格式侦探：观察下面的文件片段，猜它是哪种格式

高频一行命令

# FASTA：数序列条数
grep -c "^>" genome.fa

# FASTQ：数 reads 数
wc -l reads.fq | awk '{print $1/4}'

# SAM：统计比对率
samtools flagstat aln.bam

# VCF：数变异位点（只数 PASS）
bcftools view -f PASS variants.vcf.gz | grep -vc "^#"

# GFF：提取所有外显子坐标
awk '$3=="exon"' genes.gff
